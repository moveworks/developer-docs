# Description

Lets employees book a Tech Lounge appointment (in-person or remote), join a walk-in queue and see their position, or view and cancel an existing booking, all from chat. It creates and cancels real ServiceNow Walk-Up Experience records.

# User Experience Preview

The Purple chat preview on this page is a real conversation: book an appointment, switch to a walk-in, view both, then cancel the appointment.

# Pre-requisites

## 1. ServiceNow apps

- **Employee Slate for ITSM** (`sn_itsm_empworks`) **v2.0.3+**, which provides the `walk_in` REST API.
- **Walk-Up Experience** (`com.snc.walkup`), activated **before** installing Employee Slate for ITSM. Otherwise the walk-up records aren't created, with no install error. See [Walk-up Experience](https://www.servicenow.com/docs/r/it-service-management/walk-up-experience/walkup-experience-landing-page.html).
- **Appointment Booking** (`sn_apptmnt_booking`) and **Service Catalog** with a Tech Lounge booking catalog item.

## 2. ServiceNow connector

Uses **Service Account** auth (OAuth 2.0 Client Credentials); employees usually can't access the walk-up tables directly. The account needs:

- Read: `wu_location_queue`, `wu_m2m_location_queue_reason`, `interaction`, `sys_user`
- Write: `interaction`, and bookings via the catalog item
- The `sn_walkup.walkup_technician` role (or `walkup_manager`), so `contact_types_for_appointment` is readable

Calls run as a shared account, so the plugin looks up the employee's `sys_user` sys_id by email and passes it on every call.

Set up the connector with the [OAuth 2.0 Client Credentials guide](https://marketplace.moveworks.com/connectors/servicenow#oauth-2-0-client-credentials), then follow the [plugin installation docs](https://help.moveworks.com/docs/ai-agent-marketplace-installation).

# How This Plugin Works

- **Book an appointment.** Offers to cancel any existing appointment first, then resolves the visit type, checks slots for the next two weeks, collects a reason, and submits after confirmation.
- **Join the walk-in queue.** Offers to cancel any existing queue entry first. Remote-only locations offer booking instead. Otherwise checks in after confirmation and reports queue position.
- **View / manage.** Shows the active appointment and queue entry and offers to cancel either, asking first. Cancelling an appointment offers a rebook.

Cancelling sets the `interaction` to `closed_abandoned`; nothing is deleted. An employee can hold one appointment and one queue entry at once.

# Implementation Details

**Note:** Update instance references after installing.

## API Details

**Custom `walk_in` API** (`/api/sn_itsm_empworks/walk_in/...`, `POST`, always HTTP 200; check the body's `checkedIn` / `error`):

| Route | Purpose | Body |
|---|---|---|
| `/checkin` | Join a walk-in queue | `{"userId","locationId","reasonId","reasonText"}` |
| `/active-appointment` | Employee's upcoming appointment | `{"userId","nowUtc"}` |
| `/appointment-state` | Re-check an appointment after cancelling | `{"appointmentSysId","userId"}` |

**Standard ServiceNow APIs:**

- **Table API reads:** `sys_user`, `wu_location_queue`, `wu_m2m_location_queue_reason`, `interaction`
- **Table API write:** `PATCH /api/now/table/interaction/{sys_id}` to cancel (`state: closed_abandoned`) and to add work notes
- **Availability:** `POST /api/sn_apptmnt_booking/appointment/availability`
- **Booking:** `POST /api/sn_sc/servicecatalog/items/{catalog_id}/submit_producer`

References: [Table API](https://docs.servicenow.com/bundle/latest-application-development/page/integrate/inbound-rest/concept/c_TableAPI.html), [Service Catalog API](https://docs.servicenow.com/bundle/latest-application-development/page/integrate/inbound-rest/concept/c_ServiceCatalogAPI.html).

# What Is In Scope for This Plugin?

- Booking in-person or remote Tech Lounge appointments
- Joining a walk-in queue and reporting queue position
- Viewing and cancelling an existing appointment or queue entry
- Checking for an existing booking before creating a new one
- Saving the reason for the visit on the record

# What Is Out of Scope for This Plugin?

- Rescheduling in place (cancel and rebook instead)
- Walk-ins at remote-only locations
- Managing locations, schedules, or visit reasons
- Wait-time estimates, acting for others, notifications
